# Neural-Network-from-Scratch-in-C-plus-plus

This project implements a simple feedforward neural network from scratch in C++, without using any external machine learning libraries. It is designed for learning purposes and demonstrates how neural network operations such as forward pass, backpropagation, activation functions, and weight updates can be implemented manually using only standard C++ and matrix operations.

🚀 Features

Fully connected dense layers

ReLU activation function

Mean squared error (MSE) loss

Backpropagation

Custom matrix library (LinAlg.hpp) for:
- Matrix multiplication
- Broadcasting
- Element-wise operations
- Transposition and summation

Simple training loop

Lightweight and dependency-free

# Requirements
C++11 or later
A standard C++ compiler (e.g., g++, clang++)
